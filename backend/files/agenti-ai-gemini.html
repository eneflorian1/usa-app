Agenții AI reprezintă viitorul automatizării. În acest tutorial vei învăța să construiești un agent capabil să execute sarcini complexe folosind Gemini API.

Ce este un Agent AI?

Un agent AI este un program care percepe mediul, ia decizii și execută acțiuni pentru a atinge un obiectiv. Spre deosebire de chatbot-urile simple, agenții pot planifica și executa secvențe de pași.

  • Percepe input-ul utilizatorului
  • Planifică pașii necesari
  • Execută acțiuni (cod, API-uri, fișiere)
  • Returnează rezultatul

Instalare și Setup

bash
npm init -y
npm install @google/generative-ai express mongoose
💡
Tip

Folosește Node.js 20+ pentru suport nativ async/await și module ES6.

javascript
const { GoogleGenerativeAI } = require("@google/generative-ai");
const genAI = new GoogleGenerativeAI(process.env.GEMINI_API_KEY);

async function runAgent(prompt) {
  const model = genAI.getGenerativeModel({ model: "gemini-2.5-flash" });
  const result = await model.generateContent(prompt);
  return result.response.text();
}
⚠️
Atenție

Nu hardcoda niciodată API key-urile în cod. Folosește variabile de mediu (.env).

Concluzie

Ai construit primul tău agent AI cu Gemini! Poți extinde agentul cu tool-uri pentru web scraping, manipulare fișiere, sau integrări cu API-uri externe.
